# SMART Diet 記録 試作版

## できること
- 食品名、食品群、食べた量、1点に相当する量を入力
- 点数と摂取カロリーを自動計算
- 1〜4群別の合計、総点数、総摂取カロリーを表示
- 体重、水分、一言メモを保存
- 日付ごとに保存・更新・削除
- CSV書き出し
- スマホのホーム画面に追加可能

## 重要
この試作版には食品マスターを固定登録していません。
SMART Diet公式資料にある「1点に相当する量」を入力して使います。
記録は端末のブラウザ内（localStorage）に保存されます。
別の端末や別のブラウザとは共有されません。

## 公開
GitHub Pagesなどの静的ホスティングに、index.html / manifest.json / sw.js を置けば公開できます。

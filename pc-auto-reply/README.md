# EQUINERIS PC版自動返信（検証用）
MCPではなく既存のHTTPS食事記録APIとPCのCodex CLIを利用する。APIキーを新規発行しない。ChatGPTでのCodex利用枠に依存する。PCが稼働し、ワーカーが起動している場合だけ動く。PCの実機確認までは本番有効化しない。

## 起動
Windowsの公式Codex CLI（native codex.exe）とPython 3.10以上が必要。専用のWindowsユーザーで運用し、個人ファイル・別プロジェクトの認証情報を置かない。既存のCodexプラグイン設定はコピーしない。
```powershell
python pc_worker.py --login
python pc_worker.py
```
最初にChatGPT認証を行い、次に架空の記録で応答確認。写真を含む架空記録も別途テストする。GitHub ActionsのAPIテストを通し、さくら公開を検証したうえで、同意済みの架空テスト記録でのみ以下を試す。
```powershell
python pc_worker.py --live
```
トレーナーパスワードは画面で入力する。保存しない。60秒ごとに最大10件を取得。停止はCtrl+C。PC停止・セッション期限切れ・利用枠不足・ネットワーク異常時は停止し、既存の手動確認を使う。

## データ保全
従来のAIコメント案同意では自動返信しない。明示的な追加同意がある確認待ちの新規記録だけ対象。氏名と利用者キーはPC用一覧から除外するが、自由記述・写真に含まれる個人情報は完全には除外できない。Codexへの送信とデータ取扱い設定を確認する。写真は一時ファイルとして処理し通常終了時に削除する。異常終了時に残存し得るためPCのアクセス制限とディスク暗号化が必要。自動返信は利用者画面でAIと明示する。医療等は担当者確認に戻す。自動返信がトレーナー確認を代替するものではない。既存の手動返信や通知、MCP認証は維持する。自動返信の重複・既存確認済み記録の上書きを拒否する。

## 未検証
実際のWindows CLIインストール・ChatGPT認証・利用枠・画像認識・利用者の同意文面とデータ取扱い・さくら本番接続は別途確認する。自動返信の実行を保証しない。既存本番は検証完了まで変更しない。

02 学び

12週間プログラム

  1. オープニングの「12週間プログラムを始める」を押します。
  2. 説明を読み、「次の説明へ」で進みます。
  3. 「SMART Dietプログラムを実践する」を選び、表示される案内に沿って進めます。
  4. 「12週間の学び」で学習する週を選び、「次へ」でカードを読み進めます。
  5. 「今週の参考テキストを読む」から関連教材を確認できます。
  6. 「食事を記録する」で日々の記録へ進めます。
12週間の学びを開く

03 食事記録

自分に合う記録方法を選ぶ

食事記録画面で記録日を選び、STEP1・STEP2・STEP3のタブを切り替えます。毎回すべてのSTEPに入力する必要はありません。

STEP1　写真・メモ

  1. 朝食・昼食・夕食・間食から記録する食事を選びます。
  2. 「＋ 写真を選ぶ」で食事写真を選びます。
  3. 必要に応じてメモや食品群の項目を入力します。
  4. 「記録を保存」を押し、「記録を確認」で内容を確認します。

STEP2　食材名・分量

  1. 日付と食事を選び、食材名、分量、単位、食品群を入力します。
  2. 「食材を追加」を押し、必要な食材を入力します。
  3. 「記録を保存」を押し、「記録を確認」で確認します。

STEP3　点数・栄養

  1. 食事を選択し、「食品マスターを検索」または「食品マスターの画面で探す・記録に追加」を利用します。
  2. 食材と分量を入力し、点数と四群の小計を確認します。1点は80kcalです。
  3. 「記録を保存」を押し、1日の合計点数や食材一覧を確認します。

数値は食品や調理法により異なるため、目安として活用してください。

食事記録を開く食品マスターを開く栄養素から食品を探す

04 身体の記録

体重・腹囲を記録する

  1. 食事記録の「体重・腹囲を記録する」を押します。
  2. 記録日を選び、体重（kg）や腹囲（cm）を入力します。
  3. 「測定記録を保存する」を押します。
  4. 「体重の推移」や記録履歴を確認します。

食事記録画面上部の「体重も一緒に記録」からも体重を保存できます。

体重・腹囲の記録へ

05 振り返り

これまでの記録を見る

  1. 食事記録画面の「振り返り」を押します。
  2. 「保存済みの日付」から確認したい日を選びます。
  3. 食事記録STEP1〜3や体重・腹囲を確認します。「前の記録」「次の記録」で日付を切り替えられます。
これまでの記録を開く

06 サポート

トレーナーに確認を依頼する

  1. 食事記録を保存してから、下の「トレーナーチェックを開く」を押します。
  2. 名前・記録日・STEPを確認し、「この日の保存済み記録を読み込む」を押します。
  3. 食事の内容、写真、伝えたいことを確認します。
  4. 共有と保存への同意を確認し、「トレーナーにチェックを依頼する」を押します。
  5. 送信完了の表示を確認します。後日、同じ画面で「返信を確認する」を押します。

写真は最大4枚、1枚5MB以内。送信機能はサーバーの接続・設定が必要です。送信前に内容と同意項目を確認してください。

トレーナーチェックを開く

07 よくある質問

困ったときは

記録はどこに保存されますか？

通常の食事・身体記録は利用中のブラウザに保存されます。別端末への自動同期はありません。トレーナーへ送信した情報はサーバーに保存されます。

スマートフォンを変えたら？

別端末や別ブラウザでは以前の記録が表示されない場合があります。ブラウザのデータ消去にも注意してください。

何から始めたらいいですか？

まずはSTEP1の写真とメモから始め、慣れてきたら分量や点数の記録を活用しましょう。
